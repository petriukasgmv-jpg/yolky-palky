# 🤖 Telegram Bot - Бизнес-Стратег

Телеграм бот для AI Business Strategist на основе Groq API.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd bot
pip install -r requirements.txt
```

### 2. Получение API ключей

#### Telegram Bot Token:
1. Откройте Telegram и найдите бота `@BotFather`
2. Напишите `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный Token

#### Groq API Key (БЕСПЛАТНО):
1. Перейдите на https://console.groq.com
2. Зарегистрируйтесь
3. Создайте API ключ
4. Скопируйте ключ

### 3. Конфигурация

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
TELEGRAM_BOT_TOKEN=your_token_here
GROQ_API_KEY=your_groq_key_here
```

### 4. Запуск бота

```bash
python main.py
```

## 📝 Команды

- `/start` - Начало работы
- `/help` - Справка
- `/clear` - Очистить историю разговора

## 🏄 Как использовать

1. Найдите бота в Telegram по username
2. Напишите `/start`
3. Опишите вашу бизнес-идею
4. Получите анализ, расчеты и план действий!

## 💾 Сохранение истории

Бот сохраняет последние 20 сообщений для контекста разговора.
Это обеспечивает:
- Контекст между сообщениями
- Способность следить за линией обсуждения
- Возможность доработки идей

## ⚠️ Ограничения

- Groq Free Tier имеет rate limit (защита от перегрузок)
- История разговора хранится только во время сеанса
- Для постоянного хранения нужна БД

## 🔐 Безопасность

- Никогда не коммитьте `.env` файл!
- Храните API ключи в переменных окружения
- Используйте Railway Secrets для production

## 📈 Развертывание на Railway.app

### 1. Создайте аккаунт на https://railway.app

### 2. Подключите GitHub репо

### 3. Добавьте переменные окружения в Railway:
```
TELEGRAM_BOT_TOKEN = ваш_token
GROQ_API_KEY = ваш_groq_key
```

### 4. Создайте `Procfile`:
```
worker: cd bot && python main.py
```

### 5. Деплой автоматический!
