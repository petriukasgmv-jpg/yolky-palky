# Yolky Palky — план тестирования и улучшений

## 1. Smoke-тест после каждого деплоя

- [ ] Render показывает Build successful и Live.
- [ ] GET / возвращает статус работы агента.
- [ ] GET /health возвращает status: ok.
- [ ] missing_environment пустой.
- [ ] memory_external_dir: true.
- [ ] memory_writable: true.
- [ ] Webhook без секретного заголовка возвращает 403.
- [ ] /start отвечает один раз и не падает.
- [ ] Повторная доставка одного Telegram update не создаёт дубликат ответа.

## 2. Память и профиль

- [ ] «запомни мой бюджет 300 евро» сохраняет 300.
- [ ] «какой мой бюджет?» возвращает 300 без обращения к ИИ.
- [ ] «сохрани цель 5000» сохраняет цель.
- [ ] «какая моя цель?» возвращает сохранённую цель.
- [ ] /profile бюджет: 500; город: Вильнюс сохраняет профиль.
- [ ] Память сохраняется после перезапуска сервиса.
- [ ] /start очищает историю диалога, но не профиль.
- [ ] /clear очищает только историю.
- [ ] Два пользователя не видят память друг друга.
- [ ] Пустые и повреждённые сообщения не ломают обработчик.
- [ ] SQLite-файл находится на Persistent Disk.

## 3. Калькулятор

Проверить:

- [ ] цена, себестоимость, доставка, реклама, комиссия;
- [ ] налог считается с положительной прибыли до налога, а не с выручки;
- [ ] налог не превращается в VAT;
- [ ] десятичные числа через точку и запятую;
- [ ] нулевые и отрицательные значения;
- [ ] комиссия и налог больше 100%;
- [ ] убыток и ноль продаж;
- [ ] округление заказов всегда вверх;
- [ ] цель и прибыль за месяц;
- [ ] часы на заказ, лимит 160 часов и больше 20 ручных заказов;
- [ ] обратная проверка всех формул;
- [ ] отсутствие двойного вычитания труда владельца.

Контрольный пример: цена 1500, себестоимость 400, доставка 30, реклама 50, налог 15%. Расходы до налога 480, прибыль до налога 1020, налог 153, денежная прибыль 867, для цели 5000 нужно 6 заказов.

## 4. Ответы ИИ

- [ ] Нет данных — агент помечает допущение.
- [ ] Факты отделены от оценки.
- [ ] Нет обещаний гарантированной прибыли.
- [ ] Нет противоречивой арифметики.
- [ ] Новый запрос важнее старого ответа.
- [ ] «Продолжать» даёт следующий конкретный шаг.
- [ ] «Исправь» исправляет предыдущий расчёт, а не задаёт лишнюю анкету.
- [ ] Вопросы о памяти не отправляются в LLM.
- [ ] Длинные ответы разбиваются по лимиту Telegram.
- [ ] Нет HTML <br>, внутренних ссылок и мусорной разметки.
- [ ] Mojibake исправляется или явно помечается.

## 5. Юридические, налоговые и финансовые ответы

- [ ] Страна и форма деятельности не угадываются.
- [ ] Разделяются GPM/налог на прибыль, PSD, VSD и PVM/VAT.
- [ ] VAT не считается прибылью.
- [ ] Сумма гранта не считается доходом консультанта.
- [ ] Процент успеха гранта применяется к числу заявок.
- [ ] Ставки проверяются по официальным источникам с указанием года.
- [ ] Нет советов скрывать доходы или обходить закон.
- [ ] При юридическом выводе рекомендуется VMI/Sodra/юрист.
- [ ] При отсутствии поиска ответ обозначен как предварительная оценка.

## 6. Поиск и актуальность

- [ ] Поиск вызывается для текущих цен, законов, комиссий, технологий и политики.
- [ ] CPC, CPL и CPA не смешиваются.
- [ ] Рекламная воронка сходится обратным расчётом.
- [ ] Не используются закрытые или несуществующие площадки.
- [ ] Источник относится к нужной стране и текущему году.
- [ ] При сбое поиска агент не выдумывает данные.
- [ ] Fallback-модель сообщает, что данные требуют проверки.

## 7. Надёжность и безопасность

- [ ] Секрет webhook обязателен.
- [ ] Токены не попадают в GitHub и ответы.
- [ ] Ошибки Groq не показывают ключи пользователю.
- [ ] Повторы Telegram update подавляются.
- [ ] Медленный поиск не блокирует приём webhook.
- [ ] Ошибки Moltbook не останавливают Telegram.
- [ ] SQLite операции закрывают соединения.
- [ ] История ограничена по размеру.
- [ ] Память разделена по user_id.
- [ ] /health не раскрывает секреты.
- [ ] Внешние запросы имеют тайм-ауты.

## 8. Производительность

- [ ] Ответ webhook принимается быстро.
- [ ] Одновременные сообщения не смешиваются.
- [ ] Очередь ограничена.
- [ ] Fallback-модель работает при исчерпании основной.
- [ ] Размер контекста ограничен.
- [ ] Частые ошибки не вызывают бесконечные повторы.
- [ ] Фоновый Moltbook не ломает Telegram.

## 10. Критерий готовности

Агент готов к рабочему использованию только если smoke-тесты проходят, память переживает перезапуск, калькулятор проходит контрольные формулы, вопросы памяти не вызывают LLM, webhook закрыт секретом, секреты не раскрываются, юридические ответы маркируются по уверенности, а commit из /health совпадает с последним проверенным commit.
