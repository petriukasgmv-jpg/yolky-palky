Ёлки-палки — AI Business Strategist

О проекте

Ёлки-палки — это персональный ИИ-бизнес-стратег и практический помощник.

Главная задача проекта — помогать анализировать бизнес-идеи, находить реальные возможности для заработка, рассчитывать экономику проектов и превращать идеи в конкретные планы действий.

Основные возможности

- анализ бизнес-идей;
- оценка реалистичности проектов;
- расчёт вложений и расходов;
- прогнозирование выручки и чистой прибыли;
- расчёт окупаемости;
- анализ рисков;
- поиск вариантов запуска с минимальными вложениями;
- разработка пошаговых планов;
- помощь в продажах и продвижении;
- поиск возможностей масштабирования;
- создание устойчивых источников дохода.

Главная инструкция

Основные правила и поведение агента находятся в файле:

"instructions.md"

Этот файл является базовой инструкцией для ИИ Бизнес-Стратега.

Цель проекта

Создать практичного ИИ-помощника, который помогает не просто обсуждать бизнес, а принимать решения и переходить к конкретным действиям, направленным на увеличение дохода.

Язык
